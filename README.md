# 🧹 Gerador de Escala de Faxina

Um sistema simples, rápido e responsivo para organizar a escala de limpeza da casa. Criado para substituir o uso de planilhas manuais e automatizar o sorteio das tarefas de forma justa, permitindo ajustes rápidos de última hora.

## ✨ Funcionalidades

- **Gestão de Áreas:** Adicione os cômodos da casa e defina quantas pessoas são necessárias para limpar cada um.
- **Gestão de Pessoas:** Adicione os nomes de todos que vão participar da faxina.
- **Sorteio Inteligente:** O sistema distribui aleatoriamente as pessoas entre as áreas cadastradas.
- **Edição Pós-Sorteio:** Alguém não pode fazer aquela área específica? O sistema permite que você edite os nomes diretamente no resultado gerado antes de tirar print ou compartilhar.
- **Interface Responsiva:** Funciona perfeitamente no computador ou na tela do celular.

## 🚀 Tecnologias Utilizadas

O projeto foi construído sem a necessidade de frameworks complexos, focando em leveza e facilidade de hospedagem (ideal para o GitHub Pages):

- **HTML5**
- **CSS3 (Tailwind CSS via CDN):** Para um design moderno e responsivo sem arquivos pesados.
- **JavaScript (Vanilla):** Para a lógica de randomização e manipulação da interface.

## 🛠️ Como usar

1. Acesse a página do projeto.
2. Na seção **Áreas**, adicione os cômodos (ex: *Cozinha*, *Banheiro*, *Sala*) e defina quantas pessoas farão cada área.
3. Na seção **Pessoas**, adicione os nomes dos participantes (ex: *Pedro, Mishael, Kauã*).
4. Clique no botão **Sortear**.
5. O resultado aparecerá na tela. Se precisar trocar alguém de lugar, basta clicar no nome da pessoa e digitar o novo nome.
